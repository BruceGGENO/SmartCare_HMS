# SmartCare HMS

A web-based Hospital Management System that unifies clinical, administrative, financial, and patient-facing workflows in one platform.

Built with **.NET 8**, **ASP.NET Core Web API**, **ASP.NET Core MVC / Razor Pages**, and **SQL Server**, following **Clean Architecture**.

## Approved Technology Stack

| Layer | Technology |
|---|---|
| Platform | .NET 10 (C#) |
| Web API | ASP.NET Core Web API |
| Staff UI | ASP.NET Core MVC / Razor Pages |
| Database | SQL Server 2019+ |
| Data access | ADO.NET (`Microsoft.Data.SqlClient`) + stored procedures |
| DB tooling | SQL Server Management Studio (SSMS) — dev/DBA only, not runtime |



---

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- SQL Server Management Studio (SSMS)
- Visual Studio 2022 (17.8+) or VS Code with the C# Dev Kit
