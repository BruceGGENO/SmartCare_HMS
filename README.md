# SmartCare Hospital Management System (HMS)



## Project Overview



SmartCare HMS is a full-stack web application designed to improve hospital operations, patient management, clinical services, financial management and healthcare resource allocation.



## Technology Stack



- Front-end: React, JavaScript, CSS and Vite

- Back-end: ASP.NET Core Web API and C#

- Database: Microsoft SQL Server

- Data Access: ADO.NET

- Architecture: Clean Architecture

- Version Control: Git and GitHub

- API Testing: Postman
